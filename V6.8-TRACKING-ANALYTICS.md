# v6.8 — Tracking & Analytics

A new **Admin → Tracking & Analytics** section manages Google Tag Manager (GTM), Google Analytics 4 (GA4) and Meta Pixel from the CMS.

## Setup

1. Open **Admin → Tracking & Analytics**.
2. Turn on **Enable website tracking**.
3. Enable the services you want and paste only their IDs:
   - Google Tag Manager: `GTM-XXXXXXX`
   - Google Analytics 4: `G-XXXXXXXXXX`
   - Meta Pixel: numeric Pixel ID, for example `123456789012345`
4. Keep **Track lead & conversion events** enabled to send form/brochure/career-test events.
5. Keep **Track WhatsApp and phone clicks** enabled if these contact actions should be measured.
6. Click **Save Tracking**.

The server injects the official snippets into every public HTML page automatically. Nothing needs to be pasted into each course page.

## Important duplicate-tracking note

GTM is a container. If GA4 or Meta Pixel are already installed as tags inside the GTM container, do not also enable the same direct GA4 / Meta integration in this CMS unless duplicate tracking is intentional.

## Conversion events

The frontend now sends these non-PII events:

- `lead_submit`
- `course_enquiry`
- `contact_submit`
- `placement_assistance_submit`
- `brochure_lead`
- `brochure_download`
- `career_test_complete`
- `newsletter_subscribe`
- `whatsapp_click`
- `call_click`
- `testimonial_video_open`

Only contextual fields such as course, branch, page, source, recommendation and form type are sent. Name, phone and email are intentionally excluded from analytics event payloads.

## Google Tag Manager

GTM receives each custom event through `dataLayer`, for example:

```js
{
  event: 'brochure_lead',
  course: 'CMA USA',
  source: 'Website Brochure',
  page: '/courses/cma-usa.html'
}
```

Use GTM Custom Event triggers with the event names above to configure Google Ads conversions or other tags.

## GA4

When direct GA4 is enabled, the same event names are sent with `gtag('event', ...)`.

Use GA4 Admin → Events / Key events to mark the relevant conversion events as key events.

## Meta Pixel

The website automatically sends `PageView` on page load.

- `lead_submit` and `brochure_lead` are sent as the standard Meta **Lead** event.
- `newsletter_subscribe` is sent as **CompleteRegistration**.
- Other actions are sent as Meta custom events using the same event names.

## Testing

- GTM: use **Preview / Tag Assistant** before publishing the container.
- GA4: use **Realtime** and **DebugView**.
- Meta: use **Events Manager → Test events**.

The CMS page preview (`?cms_edit=...`) does not load tracking scripts, so editing pages does not create false analytics traffic.
