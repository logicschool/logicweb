# v6.7.1 — Odoo leads.logic field validation fix

- Fixes `Invalid field contact_name on model leads.logic`.
- Native `leads.logic` mapping remains:
  - `name` <- website `name`
  - `phone_number` <- website `phone`
  - `email_address` <- website `email`
  - `preferred_course` <- website `course`
  - `leads_source` <- automatic website source record
- Optional Custom Field Mapping JSON is now checked against Odoo `fields_get`. Invalid/legacy fields are ignored instead of failing the lead creation.
- For the standard Logic custom lead model, Custom Field Mapping JSON can be left blank.
