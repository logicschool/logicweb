# v6.7.2 — Odoo Many2one Lead Source Fix

Fixes the direct Odoo sync error:

`column "leads_source" is of type integer but expression is of type integer[]`

## Cause
The `leads.sources.create()` RPC call was passing a list-of-values inside another list. Odoo treated it as a multi-create operation and could return `[831]` instead of `831`. `leads.logic.leads_source` is a Many2one field and requires one integer record ID.

## Fix
- Source creation now passes one values dictionary to `create()`.
- If an Odoo/custom implementation still returns an array, the integration extracts the first ID.
- The ID is normalized to a number before assigning it to `leads_source`.
- Custom Mapping JSON is no longer allowed to overwrite `leads_source` on `leads.logic`; the source is resolved natively.

## Recommended direct-mode settings
- Model: `leads.logic`
- Custom Field Mapping JSON: leave blank unless additional custom fields are required.
