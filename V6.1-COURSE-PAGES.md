## Replacing course icons from the CMS

Every icon on the new course-detail sections is a normal `<img>` element, so it can be replaced without editing code.

1. Open **Admin → Media Library**.
2. Upload the icon file.
3. Open **Admin → Page Editor** and select the course page.
4. Click the icon in the live preview.
5. In the right-side inspector, click **Choose from Media**.
6. Select the uploaded icon.
7. Click **Apply Changes**, then **Save Page**.

The inspector now shows the recommended design size when a course icon is selected.

## Icon design size

Use one standard source size for every course-detail icon:

- **Canvas:** 256 × 256 px
- **Aspect ratio:** 1:1 square
- **Preferred format:** SVG
- **Raster alternatives:** transparent PNG or WebP
- **Background:** transparent is preferred
- **Safe artwork area:** roughly 192 × 192 px centered inside the 256 × 256 canvas
- **Website display size:** 56 × 56 px on desktop, responsive on mobile

For SVG files, use a `viewBox="0 0 256 256"` so every icon aligns consistently.

Avoid placing text inside icons because it becomes difficult to read at the final 56 px display size.
