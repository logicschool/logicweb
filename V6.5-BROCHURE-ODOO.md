# v6.5 — Brochures + Odoo / CRM Direct Lead Sync

## Brochures
Open **Admin → Brochures**.

- **Full course brochure**: upload one PDF, enable it, and save. A download button appears in the homepage hero.
- **Individual course brochures**: each of the 12 course pages has its own PDF slot. Upload a PDF, enable the button, and save.
- Maximum brochure upload size: **30 MB per PDF**.
- PDFs are stored under `uploads/brochures/`.

The brochure buttons are generated from CMS settings, so you do not need to edit each course page manually.

## Odoo / CRM lead sync
Open **Admin → CRM / Odoo**.

### Odoo direct mode
Fill in:
- Odoo base URL, e.g. `https://yourcompany.odoo.com`
- Database name
- Odoo login / username
- API key
- Model (normally `crm.lead`)

The website stores the lead locally first and then sends it server-side to Odoo. The API key is stored in `data/integrations.json` and is not returned by the public settings API.

Standard fields sent to `crm.lead`:
- `name` — Website Lead - customer name/phone
- `contact_name`
- `phone`
- `email_from`
- `description` — course, branch, mode, source, page and other context
- `type` — lead

If your Odoo database has custom fields, use **Custom field mapping JSON**. Example:

```json
{"x_studio_course":"course","x_studio_branch":"branch"}
```

The left side is the exact Odoo field technical name; the right side is the website form field name.

### Webhook mode
If your Odoo configuration uses an automation/webhook instead of direct API access, select **Webhook / automation URL**, enter the URL and optionally a bearer secret.

## Important
Direct Odoo connection is possible, but your Odoo hosting/account must permit API access and the API user must have permission to create CRM leads. Custom mandatory fields or Studio fields may require additional mapping.
