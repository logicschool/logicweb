Global typography

Individual text

For a single heading or paragraph, open Page Editor, select the element, then use Element typography. An individual value overrides the global setting.

Safe reset

Turning custom typography off restores the original premium design typography without deleting your saved values.

Send every website enquiry directly from this server to Odoo CRM or to a CRM webhook. Local lead storage remains enabled as a backup.

Connection

For your Logic Odoo module, use model leads.logic. Name, mobile, email, preferred course and website source are mapped automatically. Custom mapping is only needed for extra fields.

How lead delivery works

1Visitor submits a website form
2Lead is saved locally in Leads & Forms
3The server sends the same lead directly to Odoo / webhook
4Sync success or error is recorded below
Credentials stay server-side.

The Odoo API key and webhook secret are stored in data/integrations.json and are never returned through the public website settings API.
