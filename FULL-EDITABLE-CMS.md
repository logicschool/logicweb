# Full Editable CMS update

This build makes the homepage hero and general page content easier to edit without code.

## Added

- Dedicated Homepage Hero quick editor in Admin → Page Editor.
- Separate editable hero title lines so the highlighted third line can be changed independently.
- Direct text editing: double-click visible text in the page preview.
- Plain-text editor and rich inner-HTML editor in the element inspector.
- Text color, background color, alignment, line height, letter spacing and border-radius controls.
- Duplicate, move up, move down and delete controls for selected elements.
- Existing per-element font size/weight and animation controls remain available.
- Page backups are still created when you save.

## Editing the hero

Open Admin → Page Editor → Homepage. Use the Homepage Hero panel, click Apply to Preview, then Save Page.

## Editing other content

Click an element in the preview or double-click text to edit it directly. Save the page when finished.
