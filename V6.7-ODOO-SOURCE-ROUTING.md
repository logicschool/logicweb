# v6.7 — Logic Website → Odoo Source Routing

This update preserves the existing public pages and adds source-aware Odoo lead delivery.

## Automatic source labels

The website now sends these Odoo lead sources automatically:

- Brochure download → `Website Brochure`
- Career Test → `Website Career Test`
- Placement Assistance → `Website Placement Assistance`
- Contact form → `Website Contact`
- General enquiry / counselling forms → `Website Enquiry`

Newsletter subscriptions stay in the website lead store because the current `leads.logic` Odoo model requires a mobile number.

## Fields sent to the supplied Logic Odoo module

When using model `leads.logic`, direct mode maps automatically:

- Website `name` → Odoo `name`
- Website `phone` → Odoo `phone_number`
- Website `email` → Odoo `email_address`
- Website `course` → Odoo `preferred_course`
- Website source label → Odoo `leads_source`

The direct integration searches `leads.sources` for the source label and creates it when it does not exist.

## Recommended setup with the patched Odoo module

Use **Admin → CRM / Odoo → Webhook / automation URL**.

Webhook URL:

`https://YOUR-ODOO-DOMAIN/api/wp/callback`

No custom mapping JSON is required for the five standard fields above.

The matching patched Odoo module accepts `name`, `phone`, `email`, `course`, and `source` and creates the lead in `leads.logic`.

## Direct JSON-RPC mode

You can alternatively use **Odoo direct (JSON-RPC)** with:

- Model: `leads.logic`
- Custom mapping: leave blank unless extra fields are required

Source creation/resolution and the standard Logic fields are handled automatically.
