# Typography CMS

The admin panel now includes **Typography** in the left sidebar.

## Global controls

- Enable / disable custom typography without losing saved values.
- H1 size, mobile size and weight.
- H2 size, mobile size and weight.
- H3 size, mobile size and weight.
- Paragraph size, mobile size and weight.
- Navigation size and weight.
- Button size and weight.
- Label / eyebrow size and weight.
- Live preview and Reset Defaults.

Custom typography is **off by default**, so the existing premium design remains visually unchanged until you enable and save the typography settings.

## Individual element controls

Open **Page Editor**, select an element, and use **Element typography** to set a specific font size and weight. These inline values override global typography for that element.
