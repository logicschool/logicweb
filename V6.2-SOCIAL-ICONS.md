# v6.2 — Editable Social Icons

Admin path: **Branding & Global → Social icons & links**.

Each social tile now has:
- Platform / label
- Profile URL
- Icon / image URL
- Choose / Upload Image button using the existing Media Library
- Image fit mode:
  - **Contain** for transparent SVG/PNG icons
  - **Cover & clip** for photos, logos, or artwork that should fill the rounded tile
- Add and remove social tiles, so you are not limited to four platforms.

## Recommended design size
- Artboard: **128 × 128 px**
- Ratio: **1:1 square**
- Website display box: **38 × 38 px**
- Best format for icons: **SVG**
- Also supported: transparent PNG / WebP
- For Contain mode, keep the important icon artwork roughly inside the central **72–88 px** area of the 128 px artboard.
- Cover & clip mode can use a full-bleed square image; the website automatically clips it to the rounded box.

After changing social settings, click **Save global settings**. The updated icons and links are applied across all pages that use the standard footer.
