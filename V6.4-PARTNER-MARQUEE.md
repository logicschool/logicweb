# v6.4 — Homepage Placement Partner Auto Slider

The homepage Placement Partners logo row now runs as a smooth, continuous marquee.

## Behaviour
- Automatic leftward movement with a seamless loop.
- Constant linear speed: no snapping between slides.
- All partner cards remain editable in the normal CMS Page Editor.
- Runtime duplicates are created only in the public page; they are not saved into the CMS HTML.
- The CMS editor keeps the static grid so logos remain easy to select and replace.
- On devices with “Reduce Motion” enabled, automatic movement is disabled and the row becomes manually scrollable.

## Speed
The default duration is calculated from the number of partner cards (about 27 seconds for 6 cards). To change it manually, set the CSS custom property on the partner row, for example:

`--partner-marquee-duration: 34s;`

A larger number makes the movement slower.
