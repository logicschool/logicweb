# v6.6 — Brochure Lead Gate

## Visitor flow
1. Visitor clicks a brochure button on the homepage or a course page.
2. A premium modal asks for full name and mobile/WhatsApp. Email is optional. The full-course brochure also lets the visitor choose a course interest.
3. On submit, the server creates a lead with `formType: Brochure Download` and `source: brochure-download`.
4. If CRM / Odoo is enabled, the same lead is forwarded automatically using the existing integration.
5. The server returns a short-lived, one-time download link and the PDF downloads.

## Lead fields
The lead includes name, phone, email, course, page, brochure kind and brochure label. It appears under **Admin → Leads & Forms** and in CSV exports.

## Security / gating
The public settings endpoint does not expose the brochure PDF URL. A successful form submission creates a random download token valid for 10 minutes and usable once. Local uploaded PDFs are served with `Content-Disposition: attachment`.

## Backend
Keep managing brochure PDFs from **Admin → Brochures**. No additional setup is required.
