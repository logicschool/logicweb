# v6.3 Homepage additions

## Featured testimonials on the homepage
The homepage now includes three featured student-story cards. YouTube links use the website's existing in-page YouTube modal.

To edit a testimonial:
1. Open **Admin → Page Editor → Home**.
2. Select the testimonial card.
3. Replace the thumbnail image from Media Library.
4. Edit the student/story text.
5. Change the card link to the approved YouTube video URL.
6. Save the page.

The **See more testimonials** button links to `testimonials.html`.

## Placement partner logo section
The homepage includes six editable partner-logo tiles inspired by a clean hiring-partner strip.

The supplied logos are neutral placeholders only. Replace them with approved employer/placement-partner logos before publishing partner claims.

Recommended logo artwork:
- Canvas: **320 × 120 px**
- Preferred: **SVG** or transparent **PNG/WebP**
- Keep the actual mark centred with comfortable whitespace.
- The website uses `object-fit: contain`, so different logo proportions remain clean inside the same card.

To replace a logo:
1. Upload it in **Admin → Media Library**.
2. Open **Admin → Page Editor → Home**.
3. Click the partner image.
4. Choose the uploaded image from Media Library.
5. Update alt text with the company name.
6. Save the page.

You can duplicate or remove partner cards from the visual/source editor as the approved partner list changes.
