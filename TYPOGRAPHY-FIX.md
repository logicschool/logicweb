# Typography CMS fix

This build fixes the typography controls so they are easier to use:

- Moving any font-size slider or changing a font weight automatically enables Custom Typography.
- The primary action is now **Save & Apply**.
- Saved typography is visible inside the visual Page Editor preview as well as the live website.
- Additional Plus Jakarta Sans weights (400 and 500) are loaded so heading weight changes are more visible.
- To restore the original premium responsive typography, turn off **Enable custom typography settings** and click **Save & Apply**.
